# Avis commercial

SiLeMIO Stage Monitoring est un logiciel commercial propriétaire proposé au
prix de 49 € TTC pour une licence permanente.

La distribution publique contient les installeurs vérifiables par SHA-256, les
notes de version et la documentation utilisateur. Le code source,
les outils internes de délivrance des licences et les secrets de signature ne
font pas partie de la distribution publique.

Le backend ASIO est fourni sans garantie de compatibilité avec tous les drivers
ou matériels. Une validation sur le système cible reste indispensable avant un
usage live critique.
