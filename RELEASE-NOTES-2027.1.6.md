# StageMon 2027.1.6 — Windows

## Français

StageMon explique dès l'ouverture que son utilisation reste gratuite et
complète sans code de licence ni activation en ligne. Pendant les 30 premiers
jours, le rappel se ferme immédiatement ; ensuite, un décompte de cinq secondes
précède l'accès, sans limiter les fonctions. Une licence permanente facultative
supprime le rappel et l'attente. Son prix, ses codes et ses droits ne changent
pas. Les messages d'activation et les conditions d'usage hors ligne sont plus
clairs. Aucun paquet Mac 2027.1.6 n'est inclus dans cette version Windows.

## English

StageMon now explains up front that it remains fully usable for free, without a
license code or online activation. During the first 30 days, the reminder closes
immediately; afterwards, a five-second countdown precedes access, with no
feature limits. An optional permanent license removes the reminder and the wait.
Its price, codes and rights are unchanged. Activation messages and offline-use
conditions are clearer. No Mac 2027.1.6 package is included in this Windows
version.
