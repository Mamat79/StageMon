# StageMon 2027.1.7 — Windows

**Cette livraison concerne Windows 2027.1.7. Les paquets et notices macOS restent en 2027.1.6.** Les nouveaux paquets Mac seront publiés après leur propre qualification. Les anciennes releases sont conservées.

**This release delivers Windows 2027.1.7. macOS packages and specific manuals remain at 2027.1.6.** New Mac packages will be published after their separate qualification. Previous releases are preserved.

The Matrix places return controls above the source list. Monitors A and B
remain visible and operable while a configured C–F circuit is selected.
Cue selection, Always sources, levels, mute, clear, A/B link and cue snapshots
retain their existing behavior.

Input/output drivers and devices and the physical output summary are grouped
in a contextual panel. Engine status and Start/Stop stay visible across views.
At narrow widths, use the panel arrow to reopen configuration. The table
separates A/B cues from Always A/B columns; secondary columns remain
available through Columns.

Light and dark themes and French/English labels have been refreshed. F10
still moves keyboard focus to File. Project formats, import/export, audio
processing and the trial and licensing terms described in 2027.1.6 are
unchanged.
